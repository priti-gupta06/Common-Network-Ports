# Common-Network-Ports
create a reference sheet of commonly used ports and protocols.


Project Overview :

This project provides a reference sheet of commonly used network ports, protocols, and services. It helps beginners understand network communication and the purpose of standard port numbers.

Objective :

To learn about common network services and identify the port numbers and protocols associated with them.

Tools Used :

- Google Sheets
- Web Browser

Common Ports Covered :

- Port 22: SSH – Secure remote access
- Port 25: SMTP – Email transfer
- Port 53: DNS – Domain name resolution
- Port 80: HTTP – Web communication
- Port 443: HTTPS – Secure web communication
- Port 587: SMTP submission – Sending email

Key Learnings :

- Understood the purpose of network ports.
- Identified commonly used TCP and UDP ports.
- Learned the difference between HTTP and HTTPS.
- Understood how DNS, SSH, and SMTP work.
- Practiced organizing technical information in Google Sheets.

Deliverable :

A reference sheet of commonly used network ports, protocols, and their purposes.

Interview questions :

Q1) what is port 443? 
    Its a default network port used for HTTPS (Hypertext Transfer Protocol Secure) traffic,
    which encrypts data between a user's browser and a web server using SSL/TLS.

Q2) what is port 53 ?
    Port 53 is the default network port used by the Domain Name System (DNS) to translate human-readable website domain names into numeric IP addresses via UDP and TCP.

Q3) what is SSH ?
    The SSH port is the specific network channel used by the Secure Shell (SSH) protocol to establish encrypted, secure connections between a client and a remote server.

This project improved my basic understanding of networking concepts and common network services. These fundamentals are useful for cybersecurity, network troubleshooting, and system administration.
